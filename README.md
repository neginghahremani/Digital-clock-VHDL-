# Digital Clock (VHDL)

A digital clock circuit implemented in VHDL, with a testbench for
simulation and functional verification.

## Features
- Seconds, minutes and hours counters
- Synchronous reset
- Self-checking testbench with simulated clock signal

## Files
- `digital_clock.vhd` — main clock module
- `digital_clock_tb.vhd` — testbench

## Simulation
Open the project in ISE (or Quartus / Vivado), compile both files,
set the testbench as the top-level entity, and run the simulation to
view the output waveform.
